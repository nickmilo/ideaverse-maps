A map inside a note (Nick: "like Bases can be embedded… the same with a MOTI saved view").

- **Code block:** write this in any note and the saved view appears there, in Reading view and Live Preview:

  ````
  ```moti
  view: Annual Review
  height: 620
  ```
  ````

  `height` is optional (480 by default). A bare name on its own line works too.
- **File embed:** `![[Annual Review.moti]]`. A .moti file holds one saved view as plain JSON, so it stands on its own. To make one, run the command **Make an embeddable file for a saved view**: it writes the file beside your saved views and copies the embed link. This uses Obsidian's embed registry (how it embeds images and PDFs), which isn't part of the public plugin API; if a future Obsidian drops it, the code block still works.

An embedded map starts only when it scrolls into view. Until you click into it, the page scrolls past it as usual and the note panel stays tucked away. It fits the saved view to its own size, and it never changes your main map's settings or your views file.
