## What's new in 0.8.13

- **Every map's settings in Starfield's tighter look.** In each map's gear, a set of choices (Emergence's Main, Space-Time and Planetarium, say) is now one compact row with a line about the one you're on beneath it. Off | On rows (Subfolders, Bands) are plain switches, and switches sit together in one list. The empty "This map" heading no longer shows on maps where nothing follows it.
- **Scoring opens with where the levels start.** The Balance levels switch and the Level 5, 4 and 3 sliders now come first, before the link weights, so someone new sees them right away.
