## What's new in 0.7.47

- **Tours get their own button**, a route icon just left of Capture. Record a tour, name it and play it there. Saved (the telescope) now holds only your views. While a tour records, the Tours button turns red.
- **Even spacing on the left.** Sync, Focus, Saved and Display are now all the same width, with the same gap between them.
- Fixed: the Saved button no longer turns back into "★ Saved" text after you record a tour.
