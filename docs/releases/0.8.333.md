# 0.8.333

- **The Links HUD swing rises above the disk.** A note's links tend to lie in a disk round it (its accretion disk). When a pick swings into view, the ship now also climbs to about 30° above that disk, so the links fan out round the note instead of stacking into a line, and the pick still rests about a third of the way out. With only a few links, it rises 30° above level.
