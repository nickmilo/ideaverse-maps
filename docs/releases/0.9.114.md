# 0.9.114

- **The spot preview comes to the Links HUD.** Hold ⌘ over a row in the map's Links HUD:
  - **A note that links to the picked note:** the card shows the passage where it does, rendered, with the link marked.
  - **A property link:** the card names the property.
  - **A note the picked note links to:** its opening, as before, with the line saying so.
- The Links pane and the Links HUD now share one copy of the spot preview, the file-name emoji rule, the level colors and the order explanations (`src/spot.js`), so the two can't drift apart.
