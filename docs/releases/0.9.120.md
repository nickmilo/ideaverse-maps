# 0.9.120

- **The Recents pane (first pass).** Commands: **Open the Recents pane** (right sidebar) and **Open the Recents pane in a new tab**. It lists the 100 notes changed most lately, newest first, as the Recents HUD does, built like the Links pane:
  - **The header:** count, quiet search, folder filter, and a Display menu in Left · Middle · Right:
    - Left: orbs, emojis (the file name's own with a dot)
    - Middle: Idea Emergence level colors, day headers (Today, Yesterday, This week, This month, Earlier)
    - Right: time since modified, on by default
  - **The note you're in** is marked.
  - **Rows:** click opens, ⌘-click opens a new tab, drag into a note to link it, ⌘ for the preview. A recent note that links to the one you're in shows the spot where it does.
  - **Excluded folders:** the folders in Settings' exclude list stay out, as on the map.
