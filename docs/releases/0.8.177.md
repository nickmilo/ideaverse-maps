Previews use the same keys as the rest of the map (Nick: Shift-click on a preview opened the support note, which was confusing). In the Compass and the Cockpit:

- **Click** a preview to edit it where it is.
- **Shift-click** opens it in a new orb (tab).
- **⌘-click** (Ctrl on Windows and Linux) opens it as the support note on the right.

The hover hint says so: "click to edit · ⇧ new orb · ⌘ support note".
