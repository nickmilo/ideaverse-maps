## What's new in 0.8.28

Tabs come to the map's editors, as orbs. All of it lives under **Display → Edit mode (experimental)**.

- **Tabs, shown as orbs.** Each orb along the top of the map is a tab for the main editor, and the orb with the ring is the note you're on. Hover an orb for its name, click it to switch, and click its × (or middle-click it) to close it. **Show orbs (tabs)** turns them on or off, and **Show orb names** writes each name under its orb, slightly tilted so the names don't run into each other.
- **Shift-click opens a new tab:** on a note on the map, or on a link in any editor.
- **Pin the main editor.** The pin button in its header keeps its note. A note you then pick, on the map or from a link in the editor, opens as the support note on the right, so you can work from a map note into each note it gathers and back. A plain click on an unpinned editor replaces its note, as in Obsidian.
