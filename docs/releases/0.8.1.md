## What's new in 0.8.1

- **Saved views follow you to your other devices.** The folder you pick for the views file is a plugin setting, and plugin settings only travel with Obsidian Sync when "Installed community plugins" is on, separately from your files. So a phone could have the file but not know where to look. Now a device with no folder set finds the views file already in your vault and uses its folder.
- **Changes arrive live.** When the views file changes under the map (a sync from another device, say), Saved updates on the spot. Views you added, renamed or deleted on one device show up the same way on the other, without reopening the map.
- **No stray starter views.** A new device no longer adds its example group (Base) to a views file that already has your views.
