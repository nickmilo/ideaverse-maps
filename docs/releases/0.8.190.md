- **Your own order of maps**: drag a map up or down the Maps menu, across the divider if you like. The quick keys follow the new order, except Linear Calendar, which stays 0, and Base Builder, which stays \. Once you've changed the order, a small **Reset order** appears at the bottom of the menu. It asks first: "Are you sure you want to return to the default ordering?"
- **Display → Edit mode → Editor theme:** the second choice is called **MOTI** (Maps of the Ideaverse's own look) instead of "Map".
