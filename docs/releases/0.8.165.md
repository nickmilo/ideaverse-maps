Cockpit Wander Mode fixes (Nick):

- **Arriving:** the ship swings smoothly round the note, the same arc as elsewhere, instead of cutting to a new view. Wander now waits for the swing to finish before it starts lingering.
- **The non-stop hyperspace loop is fixed.** On arrival, the cockpit could briefly lock its suggested note before Wander saw that it had arrived. Autopilot then flew on to that note, then the next, without stopping. Wander now flies only to the note it chose, and treats arriving as arriving.
