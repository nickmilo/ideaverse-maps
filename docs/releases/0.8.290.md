# 0.8.290

- **Recents above Links can grow.** A hidden grip runs along Recents' bottom edge; the cursor changes when you're over it. Drag down to show more notes, from 7 up to 14 (double), and Links slides down to keep its place just under it. Double-click the grip for 7 again. The size is remembered.
- **Fixed:** the HUD rebuilt itself on every redraw while the relevance data wasn't ready yet. That was wasted work, and it could break a drag on its edges. It now rebuilds only when its contents change.
