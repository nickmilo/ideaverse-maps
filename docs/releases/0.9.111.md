# 0.9.111

- **The spot preview follows you with ⌘ held.** Hold ⌘ and run the pointer down the Links pane: wherever you stop, that note's spot preview stays up. Before, the card for the row you'd just left closed the new one.
- **Its line under the title is italic, with a thin line after it,** and reads "Links to the active note at the spot below.", "Links to the active note via the up property." or "The active note links to this note."
