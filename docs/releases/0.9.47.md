# 0.9.47

- **The support note's tab works like an Obsidian tab.** In the Holodeck, a link clicked in the primary note opens in the support note in the same tab as before, replacing the note that was there, so tabs don't pile up. ⌘-click opens the link in the support note and gives it a new tab. A note that already has a tab uses that tab, and a pinned tab is never replaced.
