# 0.9.3 · Deck

- **⚙ Deck settings,** top left: Show relevance scores, Show time since modified, Color links by Idea Emergence, how many Recents (5–50), and a level strip for each kind of note. Shared by every Deck and Deck Mini.

- **Link colors and relevance scores without the map open.** The Deck reads the map's own scan, so links are colored by up, related, above and below, and sorted by relevance (100 = closest), whether or not a map tab is open.
- **Every column resizes:** drag the edge of the left column, the Recents and Links column or the support column, each within limits; ⚙ → Reset column widths puts them back.
- **Recents scroll** in their own box.
- **Back and forward in Deck Mini** too.
