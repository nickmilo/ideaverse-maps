## What's new in 0.7.24

- **Show more maps in the header stays longer.** When the toolbar runs short, Find shrinks to its magnifying glass first, and only then do the map names go. In tests they now hold down to about 850px, where they used to drop out around 900px. The toolbar also checks again once a change settles (a panel opening, say), so the names come back if there's room.
- **Bookshelf: "Show bookshelf auto-index system"** is now a mini switch in Bookshelf's settings (the gear). It replaces the Index button and opens the same index panel.
