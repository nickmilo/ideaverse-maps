# 0.9.137

- **Lighter panes.** The Links pane now redraws after a save only when the save could change its list (the note itself, a note it lists, or a note that now links to it), and keeps each note's relevance once worked out, so going back to a note is quicker. The Recents pane no longer redraws on link changes, moves its highlight in place when you switch notes, and saving the note already at the top only updates its time. On a 15,700-note test vault, saves now cost both panes about nothing beyond what Obsidian itself does (they had added about 15 ms and 40 ms per save).
