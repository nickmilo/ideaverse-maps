# 0.9.147: Extensions

Starfield is links-only again. Place by coordinates, Places only, the region and route art, landmarks and runs (0.9.139–0.9.146) now come from extensions: other plugins that register through Maps of the Ideaverse's new hooks. An extension can lay the stars out, hide notes, draw over the Star Chart and the Ship, always name some notes, and add switches and buttons. When one lays Starfield out, the Ship's **Galaxy** button shows.

For plugin authors: [docs/extensions.md](../extensions.md).

The "Coordinate properties" setting is gone. An extension reads the properties it needs.
