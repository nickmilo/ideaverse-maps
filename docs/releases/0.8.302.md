# 0.8.302

**The Starship's menu, cleaned up** (Nick):

- **World is gone.** The Starship always flies Starfield; "One note's links" is retired.
- **Previews are gone from it.** The Starship's mini previews now follow Display → Note mini-previews, the one place for previews.
- **Grouped switches.** They sit under two mini headers: **HUD artifacts** (hub rings, readout, relevance scores, signposts, time dial, overview map, note card, rear-view mirror, cockpit frame) and **Cosmetic elements** (galaxy names, folder gas, folder gas+, turning orbits, lines between hubs, twinkle, turning galaxies, star haze, emojis).
- **The True or false game moved near the bottom.**
- **A small "?" after each switch.** Hover it (or tap it) for a line or two on what the switch does, in the map's own card. Relevance scores' "?" holds the full explanation that used to sit in "What's the relevance score?".
