# 0.9.115

- **The Links HUD gets the Links pane's orders and switches,** in Display → Heads Up Display:
  - **Links order:** Relative, Emergence or Relevance (Relevance by default, as before).
    - **Relative:** UP, RELATED, ABOVE and BELOW under quiet headers, with the picked note in its pill between Above and Below.
    - **Emergence:** highest level first, then link score, with the picked note in its place.
  - **Show link score** (under Relative or Emergence): the note's link score in place of relevance.
  - **Show Idea Emergence orbs:** the Holodeck tab's orb in place of the dot.
  - **Show emojis on links,** with a small dot when the emoji is in the file name.
  - **Show unrequited notes:** notes that link here when the picked note doesn't link back stay bright, and the rest dim. Drag one onto the primary note to link it.
- The pane's file-name sorts, time columns and folder filter stay in the pane. The map's own Filter already shapes the HUD.
