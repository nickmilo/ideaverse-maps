## What's new in 0.8.27

- **Open note in Emergence, Open note in Starfield.** Two new commands open the note you're on in that map, in the left editor, ready to type. Edit mode and the left-side editor switch on if they were off. Give the commands hotkeys in Settings → Hotkeys.
- **The editors take the keyboard right away** when they open, so you can start typing.
