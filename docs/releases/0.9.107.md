# 0.9.107

- **Show unrequited notes** (Display → Middle, off by default). An unrequited note links to this one, but this one doesn't link back yet: the notes still waiting for a place in a map of content. With the switch on, every other row dims, so the unrequited ones stand out.
- **Drag a row into the note to requite it.** Rows in the Links pane drag like files from Obsidian's list: drop one into the note and it writes the link, and the row dims as soon as Obsidian sees the new link.
