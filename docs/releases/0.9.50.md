# 0.9.50

- **Editor hotkeys work in the map's notes.** Move line up/down, indent and outdent, and every other editor command now reach the note you're typing in: the primary note, the support note, or the Mini Deck. They used to work about half the time: Obsidian only knew about the map's tab, so a command went to whichever editor it had last heard of, or to none. Now the editor you're in tells Obsidian it's the active one, the way Canvas does for its cards, and lets go when you click away.
