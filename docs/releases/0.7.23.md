## What's new in 0.7.23

- **The map settings (the gear) have a consistent look.** Every choice is a row like Starfield's settings, with a small label, a compact switch and a thin line between rows. This covers Boxes by, Arcs by and Shelve books by. Treemap's Subfolders and Corona and Tesla's Bands are now Off | On switches.
- **A new order for the maps list:** after the main maps come Gravity, Obsidian, Treemap, Mosaic, Bookshelf, Linear Calendar, Chord, Corona, Tesla and Base Builder. The quick keys follow the new order: 7 Treemap, 8 Mosaic, 9 Bookshelf, 0 Linear Calendar, - Chord, = Corona, [ Tesla and ] Base Builder. Show more maps in the header uses the same order.
- Fixed a stray "This map" label on Starfield's settings.
