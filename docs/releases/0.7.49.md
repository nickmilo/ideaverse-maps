## What's new in 0.7.49

- **Fixed: toolbar icons running off the edge on phones and narrow panes.** When the toolbar takes a second row, Sync, Focus, Saved and Display now start that row, ahead of Find, Tours and Capture. Nothing is pushed off the right edge, even with a long map name like Linear Calendar.
- They keep the same order and spacing everywhere. On some narrow widths, Display used to jump ahead of Saved.
