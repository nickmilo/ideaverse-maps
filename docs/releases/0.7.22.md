- **More quick keys.** After 1–9, the rest of the keyboard's top row picks up the list: **0** Treemap, **-** Mosaic, **=** Bookshelf, **[** Base Builder, **]** Linear Calendar. Each map's key shows at the end of its row in the maps menu.
