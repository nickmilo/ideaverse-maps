# 0.9.59

- **The Links pane.** The map's Links HUD as a pane of its own, for the note you're reading anywhere in Obsidian: a stand-in for Obsidian's backlinks pane. Commands: **Open the Links pane** (in the right sidebar, where backlinks sit) and **Open the Links pane in a new tab**. It follows the note you're on and sorts links the HUD's way: up and related first, then by relevance, with ← → ↔ and the level colors; then the note's own properties, one group each (collections in coral); then other notes' properties that point back to it. A search field narrows the list. Click a link to open it where you're reading, ⌘-click for a new tab, hold ⌘ over a row for a preview.
