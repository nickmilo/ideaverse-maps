## What's new in 0.8.68

- **The editors work on every map.** Edit mode's left editor, centre card and support note now open on all the maps, not just Starfield, Emergence, Compass and Arena. On maps you turn, like a globe or 3D Starfield, the camera stays where you left it.
- **A pinned editor holds against the orbs too.** While the main editor is pinned, clicking another orb opens that orb's note as the support note and the pinned note stays. Unpin to switch tabs.
