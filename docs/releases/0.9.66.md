# 0.9.66

- **Time since created in the Links pane.** While the pane is sorted by created time, each link shows how long ago it was created where the relevance score would be, just as modified time does. Display → **Show time since created** (on) is offered only while that sort is on.
- Ages past a year read in years (7y, not 2500d).
- Created time is the file's own creation date, the same one Obsidian's file list sorts by, not a `created` property.
