# 0.9.106

- **The Links pane's mini preview opens at the spot.** Hold ⌘ over a link:
  - **A note that links here:** the card shows the passage in that note where the link sits, rendered, with the link highlighted ("where it links here").
  - **A link from a property:** the card names the property ("in its up").
  - **A note this one links to:** it shows that note's opening, as before.

  The card opens beside the pane, never off screen. Click it to open the note, ⌘-click for a new tab, or drag it.
