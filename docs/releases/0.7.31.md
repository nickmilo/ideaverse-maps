## What's new in 0.7.31

Three new filters:

- **Filter → MOCs.** Every map note (Level 3 and up), the biggest first, with a search box. Check one or several, and the map keeps just those maps and the notes linked to or from them, with each map's links drawn. Switch **1 step** to **2 steps** to take in the notes linked to those too, like Focus. It's built for mapping a topic: see everything you've gathered around it at once.
- **Filter → Properties.** Every property your notes share, each opening to its values with how many notes have each. Check values to keep only those notes. Within one property, any checked value counts; across properties, a note needs a match in each. For example, check *grief* under `themes` and watch those notes fill Emergence's timeline. The search box finds properties and values.
- **Filter → Years → Organize by most recently modified.** Dates every note by when its file was last changed instead of its Date property, on every map that uses dates.

The Filter button's count includes MOCs and Properties. This first pass is about function; the busier Filter menu will get a tidy-up next.
