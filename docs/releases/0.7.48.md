## What's new in 0.7.48

**Saved (the telescope) now looks like a Filter list:**

- **The header** reads VIEWS with its count and + Group on the right, like Filter's Clear.
- **The name box** looks like Filter's search boxes, and it no longer grabs focus with a bright outline when the menu opens.
- **Save** is a quiet button, like Filter's.
- **Each view is one line:** its name in the same text as Filter's rows, with the map it opens on, small and muted, at the right. The colored two-line names are gone, and pointing at a view shows its full summary.
- **Group headers** match Filter's folding rows.
- **A view's buttons** (↑ ↓, group, Update, ×) appear only when you point at it, so names get the full width.
