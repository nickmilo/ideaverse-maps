Orbs: clicking away lets go of the current orb (Nick). Before, the orb stayed current, and the next note you picked replaced it. Now, once you click empty space (or press Esc), the orb stays but no orb is current, so the next note you pick opens in an orb of its own. Picking a note that already has an orb goes back to that orb. A pinned orb is never let go.
