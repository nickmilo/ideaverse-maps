# 0.8.219

- A brand-new note (⌘D making today's note, say) opened while the map is in front: the map picks it up with a quick rescan (only changed notes are read) and opens it as the primary note.
- ⌘O (the quick switcher) and anything else that opens a note "here" never replaces the map: the note opens as the primary note.
- Fixed: the HUD links list could stumble over a note that had just left the map.
