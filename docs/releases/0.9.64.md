# 0.9.64

- **Display settings for the Links pane.** Sort moved up to the header next to the link count, and a Display button (sliders) now sits beside it. Display's switches:
  - **Show relevance scores** (on)
  - **Color links by Idea Emergence** (on). Off, links take Obsidian's own link color.
  - **Idea Emergence headers** (off). On, links are grouped by level, highest first, under small gray headers in the style of the Holodeck's folder headers. Up and related lead each level.
  - **Show emojis** (off). Each note gets its emoji the way the map assigns them: Display → Assign emojis by folder, then the emoji base's column. A name that already starts with that emoji isn't given a second one.
  - **Show time since modified** (on). It's offered only while the pane is sorted by modified time, and shows the time in place of the score.

  Every Links pane shares these settings.
