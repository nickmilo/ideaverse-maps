# 0.9.51

- **Search a note's links.** A faint magnifier sits right after the count in the Links HUD. Click it and a slim field opens in the header: type a word and the list narrows to the links whose names contain it, with the count showing how many match (LINKS · 3/201). Folded property groups open while you search. Escape, or the magnifier again, clears it. Typing in the field never sets off the map's shortcuts.
