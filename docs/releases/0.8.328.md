# 0.8.328

- **Show the way home works in the Starship.** With Display → Show the way home on, the fewest links from the note you're at back to Home (or the note you chose) run through the stars as a yellow line, each stop named and dotted, with "N steps away" at the end. When the end is out of sight, the center note says where the line goes ("LYT Book Home · 2 steps away").
