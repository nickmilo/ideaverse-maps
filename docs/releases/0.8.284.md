# 0.8.284

**Recents and Links are one HUD** (option 2 from the mockups):

- **One panel.** Links is now a section under Recents: one background, one curve, a divider between the two, and the same rows (with the 3% hover).
- **Each section works on its own.** Tuck Recents away (its › or a click on an empty part of its section) and Links stays, moving up to the top. Tuck Links away and Recents stays. Each comes back from its own tab on the right edge.
- **Links rows read like Recents rows.** The arrow comes first, then the name, with the relevance score at the right where Recents shows the age. The list scrolls inside the panel. Hover still draws a dashed line to the note on the map. Click goes there, ⌘-click opens it as the support note, Shift-click opens a new orb.
- Display → HUD links → **Colored names** (on): each name is in its level's color (gold for an up link) instead of a dot before it. Turn it off to get the dots back.
- Display → HUD links → **Show relevance scores** (renamed from "Relevance scores"): hides the scores, as "Show time since modified" hides Recents' ages.
- The Opacity slider now sets the whole HUD's background.
