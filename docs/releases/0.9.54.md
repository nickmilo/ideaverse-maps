# 0.9.54

- **Drag notes into the map from anywhere in Obsidian.** A note's tab, a note in the file list, a search result or a link can be dropped:
  - **on the tabs** (the Holodeck's column or the orb row): a line shows where it lands, and it becomes a tab there. A tab dragged in moves: it leaves Obsidian's tab bar (unless it's the last tab there). Several files dragged together become several tabs.
  - **on the primary note**: it becomes the primary note, past a pin; the primary stays pinned.
  - **on the support note**: it opens beside the primary, with a tab of its own.
  While you're over the map's tabs or notes, Obsidian's own tab-drop preview steps aside.
