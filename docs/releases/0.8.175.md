Three things:

- **Moves happen live:** when a note is moved or renamed (Cmd-M, drag in the file explorer, a rename), the map updates its path, folder and name in place and glides it to its new spot, with no rescan. The camera holds still; the note flies. On Treemap you watch it leave Efforts/Projects and land in Atlas. The note's panel and the editor strip show the new path once it lands.
- **The note's folder in the editor strip:** after the rank pill, a small folder icon and the folder's name ("Projects", "Atlas", "Vault root"). Hover it for the full path.
- **Compass previews are editable,** as the Cockpit's are. Click one to edit it where it is; Shift-click opens it as the support note on the right. Press Esc or ×, or click the map, to finish.
