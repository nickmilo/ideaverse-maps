# 0.9.73

- **Drag notes out of the Recents and Links HUD.** A row drags the way a file drags from Obsidian's file list: onto the Holodeck's tabs (a new tab, or move one you already have), onto the primary note (past a pin), onto the support note (beside, with a new tab), or anywhere else Obsidian takes a file.
- **Links pane Display, renamed and tidied.**
  - "Color links by Idea Emergence" is now **Show Idea Emergence link colors**.
  - The headers are now **Show Idea Emergence headers**, and the switch only appears while you're sorted by Idea Emergence, since that's what they group by.
