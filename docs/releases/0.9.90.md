# 0.9.90

- **The Links pane's Display menu keeps its samples on macOS.** On a Mac, Obsidian draws menus with the system's native menus by default (Settings → Appearance → Native menus), and those are plain text, so the colors, orbs and small headers disappeared. This one menu now always uses Obsidian's own menu, as Canvas does for its rich menus. Other menus still follow your setting.
