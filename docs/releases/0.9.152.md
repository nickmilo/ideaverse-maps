# 0.9.152: Tally takes the Years filter

When Tally is dated by Created date, it uses the same **Years** section in Filters as Emergence: a range of years, the Recent windows (1 day up to Year to date), fixed dates, or by modified. The rows follow it, so a short window shows days.

Its own date slider steps aside. Tally always narrows to the dates kept, so "Show notes outside the date range" doesn't appear there. Dated by another date property, Tally keeps its own slider.
