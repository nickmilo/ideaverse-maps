## What's new in 0.8.20

- **Edit mode (experimental): edit a note right on the map.** Turn on **Display → Edit mode (experimental)**, then pick a note in Starfield or Emergence. A card opens in the middle of the map, below the note, holding Obsidian's own editor: Live Preview, links, properties and your other plugins all work, and every change saves to the note as you type. The map stays all around it, with the note above the card. **Open in editor** opens it in a regular tab; **×** closes the card. Picking another note moves the card to it.
- This is the first step toward editing inside the maps. Coming next: the map redraws a note's links and level the moment you save, so you can watch a new link appear as you type it.
