# 0.8.294

- **"Color all links by Idea Emergence" follows Display → Starfield link colors.** With the switch on, links in your notes, properties, embeds and the backlinks pane use the map's link colors, so a link below is red everywhere, matching the map. The primary and support notes follow it too, including in the Starfield editor theme. Other properties stay coral either way. Turn the switch off and links below are green again.
