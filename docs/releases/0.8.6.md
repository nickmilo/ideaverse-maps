## What's new in 0.8.6

- **Every link counts toward a note's score.** Links in and links out now count every link, whether it's in the note's text or in a property: `up`, `related`, or any other. A note that links another twice (in its text and in `up`, say) counts once. Uplinks still add a little extra on top. The note panel's "linked from" and "links to", Star Chart's readout and the score all use the same counts. Collections keep their own weight. Because more links count, more notes reach Levels 3 and 4; you can move the cut-offs in **Scoring**.
- **Starfield's link colors match everywhere.** Starfield used its own colors for links (gold above, blue below), so the map, its legend and the note panel disagreed. It now uses the theme's link colors, the same as the panel and every other map: links above, links below, up, related and other properties. On a light theme they're lifted a little to show on the dark sky. The legend lists all five.
