# 0.9.65

- **The Links pane matches the Links HUD.** On Refraction Thinking the two now show the same count, order, scores and colors.
  - **Collections in coral.** With link colors on, a group's header takes its rows' color, as in the HUD: collections are coral (when Display → Collection links in coral is on, the map's own coral), other properties are slate. With link colors off, everything is plain.
  - **Relevance is the HUD's.** The pane had used its own quick shared-neighbors measure. It now runs the map's relevance walk on the same weighted graph, so scores and order match.
  - **Link colors follow the map's rule.** Up, related or a property counts only when the note itself wrote it. Before, a note that named this one as *its* related turned purple here but not on the map.
  - **Up first, as in the HUD.** Related links now sort by relevance like the rest.
  - **The count is the HUD's.** It counts links on the map's graph, so collections (drawn, never counted) no longer add to it, and they show no score.
- The Mini Deck's link colors follow the same rule.
