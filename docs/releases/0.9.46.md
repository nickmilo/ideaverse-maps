# 0.9.46

- **Deck Mini on your phone.** On mobile, Deck Mini opens as a tab (there are no pop-out windows there) and has its own ribbon icon, **Open Deck Mini**. It opens with the Recents and Links drawer out over the note; tap a note and it opens with the drawer closed, so you're reading. Open Deck Mini again to jump to another note. One tap between recent notes, no swiping between panes.
- **Fixed: Deck Mini's note was blank on a phone.** The phone layout hides any pane it doesn't think is showing; Deck Mini's editor now says it is.
