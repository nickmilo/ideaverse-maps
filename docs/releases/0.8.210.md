# 0.8.210

- Editor theme is now two whole looks instead of a mix:
  - **Obsidian:** the editors look exactly like your Obsidian.
  - **MOTI:** the editors wear the map's own theme (its background, text, lines and accent for headings, links, properties and pills), whatever Obsidian is set to. With the map on the Obsidian theme, both are the same.
- The editors follow a theme change right away.
