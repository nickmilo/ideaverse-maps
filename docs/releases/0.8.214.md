# 0.8.214

- Edit mode is how the map works now: always on, and its switch is gone from Display. Orb tabs are always on too.
- Display, flatter: Editor theme and Editor opacity sit together at the top level, then Note mini-previews (Off, Fewer, Natural, Max), then a small switch for Show orb tab names.
- No pop-up tooltips inside menus: hovering an item (Show the way home, say) no longer brings up Obsidian's or the system's label.
- HUD links: hold ⌘ over a row for its mini preview, as on the map. The switch is now called "Automatically see mini-preview on hover".
