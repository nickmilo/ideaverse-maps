## What's new in 0.8.23

Edit mode (experimental) now writes back to the map. All of it is under **Display → Edit mode (experimental)**.

- **The map reacts as you write.** Add or remove a link in a note, in the card or anywhere else in Obsidian, and the map catches up when the note saves. The new link draws itself from the note to its target, and a removed link fades out. Counts, scores and levels update, and any note that changes level sends out a ring with its new level. New notes, renamed notes and collections still wait for a rescan.
- **Links in the editors stay on the map.** Click a link inside an editor and the map picks that note, and the main editor switches to it. ⌘-click (Ctrl-click on Windows and Linux) opens it as the support note on the right. A note that isn't on the map right now opens in Obsidian as before.
- **The side editors tuck away.** The left editor and the support note each have a ‹ › button that tucks them into a tab on their edge, the way the legend and the note panel do. Click the tab to bring the editor back. The note stays open while it's tucked away.
