# 0.9.154: Cleaner styles

Housekeeping for the community directory's automated review. styles.css no longer uses `clip-path`, `:has`, `all: unset`, `scrollbar-width` or `text-decoration-thickness`. Nothing should look different:

- Book cover triangles are drawn with borders.
- Hidden scrollbars use the WebKit rule only.
- The underline under a chosen option is a thin line drawn as a background.
- A few layout rules use classes in place of `:has`.
