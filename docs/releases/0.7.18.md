## What's new in 0.7.18

- **This map's settings get their own button.** A gear right after the maps button opens the current map's variants and options. It only shows on maps that have settings. The maps menu is now just the maps.
- **A number key for every map in the list.** 1–4 are the main maps, 5 is Gravity, 6 Obsidian, and so on down to 14 for Linear Calendar. For 10 and up, type both digits. Each map's number shows at the end of its row in the maps menu.
- **Show more maps in the header** (Display, formerly Show more map names) works again. Its small map names now show whenever the toolbar row has room, and they're the first thing to go when it doesn't.
