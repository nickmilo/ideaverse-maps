## What's new in 0.8.5

- **Clear in 3D too.** Starfield 3D with Galaxy glow → Clear now matches 2D: each galaxy is a faint tinted region with no light or bright core, and every note is a crisp dot.
- **The legend follows Clear and Star Chart.** With Clear on, it says what you're seeing: every dot is a note, ringed dots are maps and hubs, a tinted region is a galaxy. With Star Chart on, it explains the three rings, and with the second layer set, the readout and the lines.
- **Star Chart's readout matches the note panel.** "IN · OUT" now counts the links written in notes, as the panel's "linked from" and "links to" do. It used to also count links in properties (up, related), so the two disagreed.
