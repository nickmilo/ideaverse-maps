# 0.8.297

**Links HUD: property links grouped by their property** (option H2, a mini switch for now). Display → HUD links → **Group property links**, on.

- **Written links come first, as before:** text, up and related, in either direction.
- **Property-only links come next, under a coral header per property:**
  - **→ GENRESHOWS · 3:** this note's own property.
  - **← GENRESHOWS · 173:** other notes' property pointing here, such as the films that list Thriller as a genre.
- Rows inside a group are coral, as property links are in the editors.
- Click a header to fold its group. Folds are remembered per property.
- A note linked both in writing and by a property stays with the written links.
- Works in the Starship's Links too.
