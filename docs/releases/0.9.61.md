# 0.9.61

- **Sort the Links pane.** A sort button beside its search field opens Obsidian's own menu: **Relevance** (the default), **Idea Emergence** (highest level first), then Obsidian's six: file name A to Z and Z to A, modified time new to old and old to new, created time new to old and old to new. Up and related stay on top in every order; the order applies inside each property group too. The button lights while you're on anything but Relevance, and every Links pane remembers the choice.
