# 0.8.301

- **Links HUD names now match their lines.** With Colored names on, each name takes the color of its link on the map or in the Starship: up gold, related purple, above blue, below green. Before, they used the note's level color, so a Level 3 note below you (Forgetting curve) was blue in the HUD and green on the map.
- **Above and below are easier to tell apart in Starfield.** Above is a touch bluer (`#6fbcff`) and below a touch greener (`#6fe08f`), on the map, in the Starship, in the editors and with Color all links. Same colors, more space between them.
