# 0.9.74

- **Relative Emergence, a third sort for the Links pane.** It groups a note's links by where they sit relative to it, the same way the note strip and the link colors do: **Up**, **Related**, **Above** and **Below**, each under a small header and ordered by relevance. Above and below follow the map's rule: level first, then score within a level, so the groups always agree with the link colors. Collections and other property groups follow after, as they do under Relevance.
