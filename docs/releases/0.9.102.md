# 0.9.102

- **An emoji at the start of a file name is that note's emoji.** With Show emojis on, the Links pane puts it in the emoji column, ahead of any folder or base emoji, and drops it from the name, so names line up. The map's emojis and the Recents HUD follow the same rule.
- **You can tell the two kinds apart:** an emoji from the file name shows at full color, and one inherited from a folder or the emoji base shows softer.
