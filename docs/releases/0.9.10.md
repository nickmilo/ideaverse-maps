# 0.9.10 · Deck

- **The Deck's note strip now does everything the map's does:**
  - **#rank** opens the score card: the four numbers (linked from, links to, link up to it, link score), why its level, the score table (count × weight = adds), and **Emergence → N above / N below**, each opening its list.
  - **Up and related** lists end in a **+** that links a note straight into the property.
  - **The folder** shows its full path on hover; click it to move the note to another folder.
  - Every list shows each note's level; click = primary, ⌘-click = a support slot, or drag it onto a slot.
