# 0.9.27

- **Editor opacity is now Editor see-through.** It says what it does: how much of the map shows through the editors. Higher is more see-through: 0% is a solid editor, 95% is nearly invisible. Your setting carries over (61% opacity reads as 39% see-through). The Holodeck's slider is the same setting under the same name, and in the Holodeck the veil over the map thins as you raise it.
