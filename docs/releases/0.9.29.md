# 0.9.29

- **Links stay in the map when their note is hidden.** A link clicked inside an editor used to fall out to a regular Obsidian tab when Focus or a filter hid its note. Now, with the primary note pinned, in the Holodeck, or on a ⌘-click, it opens as the support note. Otherwise, in Focus, it becomes the primary note and the focus moves to it.
