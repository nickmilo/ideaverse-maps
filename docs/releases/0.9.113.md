# 0.9.113

- **Idea Emergence is a plain order now:** highest level first, then link score, with no lifted up links (Relative Emergence covers those). The note itself sits in its pill at its own place in that order, so you can see where it stands among its links. With Idea Emergence headers on, it sits inside its own level.
- **Rows under a header always tuck in.** The Tuck rows switch is gone. Rows that aren't under a header stay flush.
