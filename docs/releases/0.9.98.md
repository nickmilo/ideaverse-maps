- **The Links pane's header is sized like an Obsidian pane header.** Larger LINKS · n, magnifier, Sort and Display icons and ?, so it no longer reads as the HUD's small print.

- **The ? (or its empty slot) sits over the score column,** so Sort and Display stay put and their menus leave the scores in view.
