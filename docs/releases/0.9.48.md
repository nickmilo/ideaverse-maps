# 0.9.48

- **Deck Mini is now the Mini Deck:** the Holodeck is the main one, the Mini Deck the tiny one.
- **Convert to Mini Deck.** In any note's ⋯ menu (and as a command), it turns that note's own tab into the Mini Deck: no extra tab or window. From the file list it opens one instead (on a phone a tab, on desktop a pop-out window).
- **No ribbon icon.** The mobile ribbon icon from 0.9.46 is gone; the ⋯ menu is where it lives now.
