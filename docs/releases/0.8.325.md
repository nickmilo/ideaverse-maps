# 0.8.325

- **Scatter always works in Base Builder.** Link score is now an axis, so Scatter can plot created date against link score on any set of notes (and any number property you have against either).
- **Timeline of: pick the property.** Choosing Timeline now shows a "Timeline of" menu listing every property in your vault that holds years or dates, with how many notes have it: dates, lifespan, years, published, year, and so on. Only the notes that have it stay on the map; switch back to another layout and the rest return. A span (1929 - 2018) is a bar; a lone year or date is a short one. Links (prev, next) don't count as dates.
- Fixed: a Timeline bar with an open end could fail to fade with some colors.
