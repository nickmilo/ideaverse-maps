# 0.9.52

- **Fixed: Find (⌘F) in the map's notes.** 0.9.50's hotkey fix handed Obsidian a stand-in for the editor, and Find needs the real thing, so ⌘F did nothing. It now gets the note's own view, and editor hotkeys still reach the note you're in.
- **Find's icons are readable on dark editor themes.** Previous, next, find all, close, replace and replace all were nearly invisible in a dark card. They're now a soft version of the text color, full on hover, and fainter only when there's nothing to act on. Light themes keep Obsidian's look.
