# 0.8.218

- Stay in the map: while the map is the tab in front, a note that a command opens in a new tab (⌘D for today's note, the quick switcher, a template…) opens as the primary note instead, whether or not a note was already open there. Tabs that already exist, notes the map opens itself, and its editors are left alone. A note the map doesn't have yet (just created, before a rescan) opens as usual.
