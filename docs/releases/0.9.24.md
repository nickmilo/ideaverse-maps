# 0.9.24

- **Focus follows the tabs.** While Focus is on, switching the primary note with a tab (a second click on a tab that's open beside the primary note, a drop onto the primary note, or a plain orb click outside the Holodeck) moves Focus to the new note. That includes a note outside the focused links, which used to be stuck as "filtered out". The graph behind regroups around it.
