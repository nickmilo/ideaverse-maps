# 0.9.43

- **Saved views keep the Holodeck.** A view saved in the Holodeck remembers its tabs (order and pins), the primary and support notes, the tab column's width and the sort. Opening it brings the Holodeck back just as it was. A view saved outside the Holodeck now opens with the Holodeck off; views saved before this release leave it as it is.
