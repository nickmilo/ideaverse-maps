# 0.9.69

- **The Links pane goes by each note's created property.** Sorting by created time, and the time since created beside each link, now use the note's own created date, the same one the maps use (Settings → the created properties, then a date in the note's name). The file's creation time is only the fallback, for a note with neither. Before, the pane read the file's creation time, which a copy or a sync can reset.
- Ages in years round down (3y for three and a half years).
