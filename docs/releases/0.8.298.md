# 0.8.298

- **A safety net for deleting.** "Delete current file" (its hotkey or the command palette), aimed at a note that's open in the map (the primary or support note, or the map in front), now always asks first, by name: *Delete "Ursula K. Le Guin"?* It asks even when Obsidian's own delete confirmation is off. Cancel has the focus, so a stray Enter keeps the note, and Delete sends it to the trash as before. Notes elsewhere in Obsidian are untouched by this.
