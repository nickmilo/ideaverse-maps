# 0.8.280

Link coloring, two changes:

- **Other properties and collections are coral.** Before they were slate and read like plain text.
- **Placeholder links get a dashed outline with no fill.** A placeholder is a link to a note that doesn't exist yet, a link to the note itself, or a note the map doesn't hold. The text is just barely below white. Before they fell back to the theme's link color, which could look like "related" or "below".
