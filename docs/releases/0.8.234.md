# 0.8.234

- Display → **Color all links by Idea Emergence**: every link in every note, in any Obsidian tab or window, takes the color of how its note relates: up property gold, related violet, above blue, below green, other properties slate. The relations come from the map, so the colors show while a map is open (in front or not). Readable shades on light themes, brighter ones on dark; the Starfield theme styles them too.
- The editor's score list: "above" and "below" are tinted blue and green, with their lists marked the same way, as in the note panel.
