# 0.8.224

- New theme: **Starfield**. Deep space, with pink for the chrome (no link line uses pink), green for links below so it stays clear of the blue above.
- With the editor theme on MOTI, the primary note wears it: a nebula glow in the corners and a few stars, headings in nebula colors (H2 pink, H3 violet, H6 in small capitals), properties in a dark panel with small mono labels, a pink-tinted blockquote.
- In the Starfield theme, **every link in the editor is colored by how its note relates**: up property gold, related violet, above blue, below green, other properties slate. They keep their colors as you type.
