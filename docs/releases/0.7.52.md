## What's new in 0.7.52

- **Saved starts with an example.** Someone new to the plugin finds one group, **Base**, holding two views: **Emergence** (the usual starting map) and **Emergence · Space-Time**. Seeing them shows how groups and views work. Change or delete them like any others; once deleted, they don't come back. They aren't written to your views file until you choose a folder for it.
- **The footer explains itself:** "Save the views file (.json) in", followed by the folder pill (or Choose folder).
