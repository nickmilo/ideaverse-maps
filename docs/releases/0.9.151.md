# 0.9.151: Base Builder · Tally

Base Builder has a new layout, **Tally**: a calendar grid.

- **Columns by:** a category. Each value gets its own column, glyph (ring, square, triangle, asterisk, cross…) and color.
- **Dated by:** a date. Each row is a day, week, month or year, depending on the span, with the oldest at the bottom. If the property isn't a date, Tally uses Created date.
- **Each note is a mark in its cell.** A busy day becomes a small cluster, and a column reads like a habit tracker: streaks, gaps, bursts. Click a mark to open its note.

Switching to Tally, the notes fly from where they were into their cells.
