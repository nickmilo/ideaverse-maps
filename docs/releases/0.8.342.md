# 0.8.342

- **The Starship | Chart switch is always there in the Starship.** Arriving in the Starship any other way (reopening Obsidian, Back, a saved view, the old Starship entry) used to leave you in a plain "Starship" with no switch and no C. It's now always Starfield's Starship: the switch sits beside the orb tabs and C goes to the chart.
