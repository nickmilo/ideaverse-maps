# 0.8.308

- **Display, regrouped.** Display's switches now sit under mini headers, as in the Starship menu: Link colors, HUD, Editors, Wayfinding. Opacity is now "HUD opacity". Most switches have a "?" that explains them.
- **See-through tabs** (Display → HUD). The Recents and Links tabs follow HUD opacity when this is on (as in 0.8.304). When it's off, they stay solid.
- **Starship:** removed its Relevance scores switch, which did nothing. Display's Show relevance scores now governs the Starship too. Emojis already work there; they show on the nearest stars only.
